# Akramul Hasan - Developer Portfolio (React & Next.js 15)

A modern, high-performance, dark-themed developer portfolio built with **React 19**, **Next.js 15**, **Tailwind CSS**, and **Framer-style CSS Animations**.

---

## 🚀 Features

- **Dynamic Typewriter Hero:** Interactive animated typing effect cycling through your core developer titles.
- **Glassmorphism Design:** Modern blur effects, floating glow particles, and responsive dark aesthetics.
- **Floating 3D Tech Stack Badges:** Animated badges for React, Next.js, Node.js, Tailwind, and MySQL.
- **Interactive Project Showcase:** Filter projects by category (Full-Stack, Next.js, React, Machine Learning) with live demo and GitHub source code buttons.
- **Interactive Skills Matrix:** Tabbed filters (Frontend, Backend, Database, Tools) with animated proficiency progress meters.
- **Academic & Experience Timeline:** BUBT CSE 5th Semester background, Programming Hero Level-2, and freelance milestones.
- **Interactive Contact Form:** With instant state-driven success toast confirmation.

---

## 🛠️ How to Run Locally

### 1. Instant 1-Click Launch:
Double-click `run_portfolio.bat` in this folder!

### 2. Manual Terminal Commands:
```bash
cd developer_portfolio
npm run dev
```
Open **`http://localhost:3000`** in your browser.
